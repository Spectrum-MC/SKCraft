Spectrum Launcher
=================

The Spectrum Launcher is a fork of SKCraft Launcher made to be used alongside the Spectrum Server.

It is a work in progress and is not ready for public use.

As of 2026-02-26 it is a hardfork and will not be compatible with the original SKCraft Launcher.

The last compatible commit is fcf0d89.
